Search common procedure and diagnosis codes. Type a code number or a keyword like "knee", "diabetes", or "99213".

How to use this lookup

  • CPT codes (5 digits) describe procedures and services — e.g. 99213 is an established-patient office visit.
  • ICD-10 codes (letter + digits) describe diagnoses — e.g. I10 is essential hypertension.
  • HCPCS codes (letter + 4 digits) cover supplies, drugs, and Medicare services — e.g. G0438 is a Medicare annual wellness visit.
