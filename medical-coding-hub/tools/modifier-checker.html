CPT Modifier Guide & Checker

Modifiers tell the payer how a service was performed. Search by modifier number or keyword.

Modifier basics every coder must know

  • Modifier 25 is the most-used E/M modifier — it says the visit was significant and separately identifiable from a same-day procedure. Without it, the E/M gets bundled and denied.
  • Modifier 59 / X-modifiers unbundle two procedures that NCCI edits would otherwise combine. Payers increasingly require the specific XU, XS, XP, or XE subset.
  • Modifier 50 vs LT/RT: use -50 when the same procedure is done bilaterally in one session; use LT or RT when only one side is treated.
  • Modifier 24 vs 25: -24 is for E/M during a surgical global period; -25 is for E/M on the same day as a procedure.
  • Modifier 95 marks real-time telehealth services — pair it with the correct place of service code.

Top denial-prevention tips

  1. Never append -25 to a procedure code — it only goes on E/M codes.
  2. Document the reason for every modifier in the chart note.
  3. Check payer-specific rules: Medicare and commercial payers differ on 59 vs X-modifiers.
  4. Review NCCI edits quarterly — bundling rules change.
