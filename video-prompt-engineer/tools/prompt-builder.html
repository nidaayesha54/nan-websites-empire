How to use the prompt builder

  1. Subject — be specific: not "a dog" but "a tiny corgi in a raincoat".
  2. Action — AI video needs a verb: walking, swirling, blooming, chasing.
  3. Camera — pick how the virtual camera moves. This is the #1 upgrade most beginners skip (see Lesson 2: camera language).
  4. Lighting — light is half the image. Golden hour vs neon vs moonlight changes everything.
  5. Style + mood — lock the look (cinematic, anime, noir…) and the feeling.
  6. Negative prompt — block artifacts: extra limbs, morphing faces, watermarks (Lesson 3).
