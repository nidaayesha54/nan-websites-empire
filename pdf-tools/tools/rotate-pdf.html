How to rotate PDF pages

  1. Click the box above or drag in a PDF file.

Common questions

Can I rotate only some pages?

Yes. Choose "Selected pages" and type page numbers or ranges like 2, 4-6. Page numbers start at 1.

Does rotation reduce quality?

No. Rotation only changes the page orientation flag — the content itself is untouched, so quality is identical.

Will the rotation stay after downloading?

Yes. The downloaded file has the new orientation saved permanently, and opens correctly in any PDF reader.
