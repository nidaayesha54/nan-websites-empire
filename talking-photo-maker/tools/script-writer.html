How to use this script writer

Scripts target ~2.4 words per second — the natural pace of AI voiceovers. The [pause] markers tell your talking photo tool where the avatar should breathe; most tools (HeyGen, D-ID, CapCut) honor commas and ellipses automatically. The "clean" copy strips all stage directions so you can paste plain text into any TTS engine. For deeper scriptwriting technique, read our talking head script tips guide.
