Linear Regression, Explained Simply

By NAN Marketing Agency · Updated October 2026 · 6 min read

Linear regression is the "hello world" of machine learning — and quietly one of the most-used algorithms on Earth. House-price estimators, sales forecasts, and scientific studies all lean on it. Here's the whole idea in plain English. Try the live demo →

The one-sentence version

Linear regression draws the single straight line that sits closest to all your data points at once.

The formula: y = mx + b

You already know this from school:

  • y — what you're predicting (house price)
  • x — what you're predicting from (square footage)
  • m — slope: how much y rises per unit of x
  • b — intercept: y's value when x is zero

Learning is finding the best m and b. That's the entire algorithm.

How does it find the "best" line? (Least squares)

For each point, measure the vertical gap between the point and the line — that's the error (or residual). Square each gap (so negative and positive misses don't cancel, and big misses hurt more), then add them all up. The best line is the one with the smallest total.

The beautiful part: there's a direct formula — no guessing required:

m = (n·Σxy − Σx·Σy) / (n·Σx² − (Σx)²)
b = (Σy − m·Σx) / n

Plug in your data's sums and out pop the optimal m and b. Our Regression Lab computes exactly this every time you drag a point.

What is R²? (The "how good is it" number)

R² tells you what fraction of the ups-and-downs in y your line explains:

  • R² = 0.95 — the line explains 95% of the variation. Excellent.
  • R² = 0.50 — half explained, half is noise or other factors.
  • R² = 0.05 — the line is barely better than guessing the average.

Formula: R² = 1 − (unexplained variance ÷ total variance).

The 4 assumptions (when the line lies to you)

  1. Linearity — the true relationship is roughly straight. Fitting a line to a curve gives nonsense.
  2. Independence — data points don't influence each other (no double-counting the same event).
  3. Equal spread — errors are similarly sized across x. If errors fan out, predictions at the extremes are shaky.
  4. No extreme outliers — one wild point can drag the whole line. Drag an outlier in the demo and watch it happen.

When NOT to use linear regression

  • Predicting categories (spam/not-spam) — use logistic regression or trees instead.
  • Clearly curved relationships — try polynomial features or tree-based models.
  • When you need certainty ranges without checking assumptions — the line will happily give you a wrong answer with confidence.

Linear regression in one table

Use it for: predicting numbers from numbers, establishing baselines, interpretable models.
Strengths: fast, transparent, mathematically optimal for its assumptions.
Weaknesses: straight lines only, outlier-sensitive, assumes the world is linear.

FAQ

Is linear regression machine learning or statistics?
Both — statisticians invented it 200 years ago; ML adopted it as the simplest supervised learner. The math is identical.

What's multiple linear regression?
Same idea with more inputs: y = m₁x₁ + m₂x₂ + b. One slope per feature.
