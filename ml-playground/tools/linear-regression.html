What's happening here?

Linear regression finds the line y = mx + b that minimizes the sum of squared errors — the total of all the yellow vertical gaps between points and the line. The math (computed live above):

  • Slope: m = (nΣxy − ΣxΣy) / (nΣx² − (Σx)²)
  • Intercept: b = (Σy − mΣx) / n
  • R² = 1 − (unexplained variance ÷ total variance). 1.0 = perfect fit, 0 = the line explains nothing.

Try this: drag one point far away from the others — that's an outlier, and you'll see it yank the whole line toward itself. This sensitivity is why real data scientists clean their data first.
