What's happening here?

The green curve is a polynomial fitted by least squares on the training points only (real normal-equation math, solved live). Then we measure its error on both sets:

  • Underfitting (degree 1–2): the curve is too stiff — high error on both sets.
  • Sweet spot (degree 3–5): captures the wave without chasing noise — train and test error stay close.
  • Overfitting (degree 8+): the curve wiggles through every train point — train error ≈ 0, but it swings wildly between them, so test error explodes.

The golden rule of ML: never judge a model on the data it trained on. The test set is the only honest grade — which is why every serious ML pipeline splits data before training.
