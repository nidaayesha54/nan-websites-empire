How to pick YOUR funny name

The funniest names have a personal spark: an inside joke, a favorite snack, a beloved movie. Try the dog name generator set to "Funny" style and hit reshuffle with the family — the one that makes everyone laugh out loud is the winner. Just run it through the back-door test first: you'll be shouting it in public for years, so make sure you love saying it.
