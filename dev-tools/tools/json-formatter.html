JSON Formatter, Validator & Minifier

Paste JSON below — format it, validate it, or minify it. Errors are explained in plain English.

How to use

  1. Paste your JSON into the input box.
  2. Click Format for pretty 2-space indentation, Validate to check it, or Minify for compact one-line output.
  3. Copy the result with one click.

Common JSON errors

  • Trailing commas {"a": 1,} — remove the last comma.
  • Single quotes {'a': 1} — JSON requires double quotes.
  • Unquoted keys {a: 1} — keys must be quoted.
