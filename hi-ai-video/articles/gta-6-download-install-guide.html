GTA 6 Download Guide: Install It Right the First Time

The demand is simple to explain: this is the biggest entertainment launch of the year, and everyone wants to play it on night one. But the install is 212 GB, the unlock is time-gated, and the most common mistakes on launch night are all avoidable. This guide walks through the whole process on both consoles, step by step, so you install it right the first time.

The first thing to know is what you are installing. GTA 6 is a 212 GB download, and it runs only on PlayStation 5 and Xbox Series X|S. There is no PC version at launch, and no legitimate PC download exists — any site offering one is a scam. Buy the game only from the PlayStation Store or the Xbox Store, and make sure you have 212 GB free before you start.

Before You Buy: Check Three Things

First, the console. GTA 6 does not run on PlayStation 4 or Xbox One — it needs a PS5 or an Xbox Series X|S. Second, the space: 212 GB free, not 212 GB total. Check your storage before you buy, and delete or move games you are not playing if you are short. Third, the system software: GTA 6 needs PS5 system software 26.07-14.23.00 to run properly at launch. On PS5, check under Settings, System, System Software, and install anything pending before you start the download.

Getting these three things right before you buy saves the most common launch-night frustration: a download that cannot finish, or a game that will not start, because the console was not ready. Ten minutes of checking now is worth hours of waiting later.

Downloading on PS5

On PS5, open the PlayStation Store, search for GTA 6, and buy it from the game's page. The download starts automatically after purchase. If you preloaded the game before launch, the full 212 GB is already on your console — preloading downloads the game early so you do not have to wait on launch night. What preloading does not do is unlock the game: GTA 6 stays locked until midnight local time in your store region, and until that moment the game shows a padlock.

That padlock is the single most reported "problem" of the launch, and it is not a problem at all. Check the countdown timer on the store page — that timer, not the download bar, tells you when you can play. Do not delete the game to "fix" the padlock: deleting a 212 GB install means downloading it all over again, on the busiest night of the year, for no reason.

Downloading on Xbox

On Xbox, open the Microsoft Store, search for GTA 6, and buy it there. After purchase, the game appears in your library: open the Store, go to Full Library, then Owned Games, and choose Install. Turn on automatic updates, and leave the console in Sleep mode rather than shutting it down fully — Sleep mode lets downloads and updates finish in the background, while a full shutdown downloads nothing.

The same midnight rule applies: the game unlocks at midnight in your store region. If the game shows as owned but not installed, install it from Owned Games rather than searching the store again. And if a download queue looks stuck, a full power cycle — hold the power button for ten seconds — clears it.

Redeeming a Code

If you bought a code — a gift card, a retail code, or a pre-order code — redeem it in the store before you download. On PS5, go to Settings, then Users and Accounts, then Account, then Payment and Subscriptions, and choose Redeem Codes. Enter the code exactly as printed, and the game will appear in your library ready to download. On Xbox, open the Microsoft Store and use the Redeem option from the store menu, then enter the code the same way.

Redeem the code on the account you actually play on. A code redeemed on a different account — a family member's, a second profile — will not be available on your main profile, and that is one of the most common reasons a game "disappears" after redeeming. Check the purchase in that account's transaction history if you are unsure which account used the code.

If the Download Gets Stuck

If the download will not start, or stalls at 0%, work through the verified fixes in order. On PS5, first check that system software 26.07-14.23.00 is installed, then check the countdown timer — a game that has not unlocked yet can look like a stalled download. Then go to Downloads and Uploads, Pause the download, and Resume it: that restart clears most stalls. If the game looks locked, use Restore Licenses — highlight GTA 6 on the home screen, press Options, and choose Restore License.

On Xbox, check for pending updates in My Games and Apps, then Manage, then Updates — and install everything pending for the game and the console. If the queue is still stuck, do the full power cycle: hold the power button for ten seconds, wait, and power back on. And on both consoles, check the obvious first: is there actually 212 GB free? A download that has nowhere to go will sit at 0% forever, and the fix is freeing space, not restarting anything.

Installing GTA 6 is straightforward once you know the rules: buy it from the real store, free up 212 GB, update the console first, watch the midnight countdown instead of the download bar, and never delete the install to fix a padlock.
