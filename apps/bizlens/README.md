# BizLens — Upload-Your-Data Business Intelligence

**Problem solved:** Small businesses drown in Excel sheets. Their sales data is scattered across dozens of tabs, and they can't see revenue trends, dead products, or clients quietly walking away. Hiring a data analyst or buying Power BI is overkill for a single shop.

**Solution:** BizLens is a mini Power BI in a single web page. Upload one CSV or Excel file → get a full business dashboard in ~10 seconds: KPI cards (total revenue, orders, avg order value, top month), revenue-by-month charts, product rankings, client insights — plus a **Weakness Radar** that auto-detects declining months, low-traction products, churned clients, and revenue concentration, each with a one-line suggested action.

**Features:**
- Drag-and-drop CSV / Excel (.xlsx) upload (PapaParse + SheetJS, parsed 100% in-browser — data never leaves the device)
- Smart column auto-detection (date, amount, product, client, quantity by header matching)
- One-click sample datasets: "Al-Noor Traders" (Lahore, PKR) and "Brightline Supplies" (Austin TX, USD)
- 5 views: Overview, Products, Clients, Weaknesses, Files (localStorage-persisted file manager with re-export + delete)
- PowerBI-grade dark-navy UI, Chart.js visualizations, PKR/USD formatting
