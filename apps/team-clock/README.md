**What the demo shows:** "City Cafe" with 8 staff — one-tap clock in/out, live hour counters, automatic **LATE** flags after a 10-minute grace period, real-time stats (in now / late today / on-time rate / hours logged), a live activity feed, and a "simulate morning rush" button to watch late alerts fire.

**Scenario:** Pain/solution contrast — the smudged paper register ("9:0?") vs a dashboard that sees the truth in real time.
