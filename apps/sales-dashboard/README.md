# Business Sales Dashboard — Demo

A live, interactive sales analytics dashboard for a fictional retail brand ("Nova Retail").
Built as a portfolio demo of the kind of business-intelligence web apps NAN Marketing Agency builds for clients.

## Business problem it solves
Small and mid-size businesses drown in spreadsheets. Owners can't answer basic questions at a glance:
- Is revenue growing or shrinking?
- Which products actually drive profit?
- Which regions are underperforming?

This dashboard turns raw sales data into instant visual answers — KPI cards, revenue trends, regional split, top products, and flagged high-value orders.

## What's inside
- `index.html` — complete single-file app (Chart.js via CDN, no build step)
- KPI cards: revenue, orders, customers, avg. order value with trend deltas
- Revenue-by-month line chart with target overlay
- Sales-by-region doughnut chart
- Top-products horizontal bar chart
- Recent high-value orders table with status pills
- Fully responsive, NAN navy (#0A1628) / teal (#14B8A6) theme

## Try it
Open `index.html` in any browser, or view it live in this repo.
