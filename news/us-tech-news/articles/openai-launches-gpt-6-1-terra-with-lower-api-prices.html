OpenAI Launches GPT-6.1 Terra With Lower API Prices

October 27, 2026

OpenAI has released GPT-6.1 Terra, a new model for ChatGPT Work, Codex and its API, offering lower standard pricing than its GPT-6.1 Sol sibling for work involving images and computer applications. The model launched on October 26, 2026, and is available to Plus, Pro, Enterprise and Edu users, with developer access through the API under the identifier gpt-6.1-terra.

According to OpenAI's model documentation, standard charges for GPT-6.1 Terra are $1 per million input tokens, $0.05 per million cached input tokens and $5 per million output tokens. Tokens are the units used to measure how much text and data a model processes. Those rates apply to prompts containing no more than 272,000 input tokens; longer prompts attract double input and cache rates and 1.5 times the output rate for the full request, with cache writes and some tools carrying separate charges.

Built for computer use and coding

OpenAI reported improvements in computer-use and coding benchmarks for the new model, though those results are the company's own evaluations rather than independent tests. The model is aimed at work that involves images and computer applications, a growing area as AI assistants take on more multi-step tasks inside software, browsers and development tools.

The launch continues a pattern in which AI providers offer a range of models at different price and capability levels, letting developers and businesses pick the tradeoff that fits a given task. Lower-priced models are typically used for high-volume work where cost matters most, while more capable models handle tasks that demand greater accuracy or reasoning.

Part of a fast-moving model race

The release comes during a period of rapid model iteration across the industry, with providers competing on price, speed and specialized capabilities. For developers, the practical question is often not which model is most powerful in absolute terms but which one delivers the right performance at a sustainable cost for production workloads.

GPT-6.1 Terra's positioning as a lower-priced option for image and computer-application work suggests OpenAI is targeting exactly that calculation. The model documentation lists no support for the free API tier, meaning access runs through paid plans and API accounts.
