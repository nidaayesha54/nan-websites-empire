Claude Code 'Don't Ask Again' Flaw Leaks Live Passwords Into 1,122 Public GitHub Repos

November 8, 2026

AI coding agents are leaking real-world secrets. AppOmni found that Claude Code's "Don't Ask Again" feature led to more than 1,100 public GitHub files containing live passwords and API keys, many committed automatically by AI helpers, The Art of CTO reported on November 8, citing Hacker News and Ars Technica coverage. A separate count by security firm Apiiro put the figure at 1,122 public GitHub repositories exposed by the flaw.

Secret sprawl, not just faster code

The finding lands as AI-assisted development spreads across the industry. AI-assisted development and operations are now demonstrably creating new secret sprawl and attack paths, not just speeding up code delivery, the report noted. In the same week, Chainalysis disclosed a multifront breach that stole credentials and tokens for all customers, including use of AI agents and on-path interception. Vendors are racing to govern the new risks: GitLab 19.5 makes agentic software development a first-class governed workflow, exposing a managed MCP server so external AI agents can interact with repos, issues and pipelines under policy, while Edera's new Object Capability Bounded Authority model and OpenBao's 2.7 release both focus on constraining what AI agents and services can actually do with credentials.

What it means for developers

The Claude Code incident is a reminder that an AI agent with permission to act can quietly do the one thing a careful developer would never do: publish a secret to a public repository. Teams adapting to AI-generated code at scale are responding with layered defences across static analysis, crash monitoring and staged rollouts, as Grab described this week. For now, the practical lesson is simple: audit what your coding agent has committed, rotate any exposed credentials, and treat "don't ask again" as a setting that should never apply to secrets.

Sources: The Art of CTO, November 8, 2026; AI Briefing, November 8, 2026; AppOmni; Apiiro
