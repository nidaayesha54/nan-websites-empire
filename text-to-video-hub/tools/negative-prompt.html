What is a negative prompt?

A negative prompt tells the video model what not to generate. Tools like Runway, Kling, and Luma accept a separate negative prompt; where a tool doesn't, the same terms usually work appended as "avoid ..." clauses. For the full prompting workflow, start with our prompt generator or learn the method in How to Write AI Video Prompts.
