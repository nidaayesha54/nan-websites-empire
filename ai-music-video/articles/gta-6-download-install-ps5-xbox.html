Downloading on Xbox

On Xbox, open the Microsoft Store, search for GTA 6, and buy it there. After purchase, the game appears in your library: open the Store, go to Full Library, then Owned Games, and choose Install. Turn on automatic updates, and leave the console in Sleep mode rather than shutting it down fully — Sleep mode lets downloads and updates finish in the background, while a full shutdown downloads nothing. The same midnight rule applies: the game unlocks at midnight in your store region, so a game that looks ready but will not start is usually just waiting for the clock. If a download queue looks stuck, a full power cycle — hold the power button for ten seconds, wait, and power back on — clears it.

Redeeming a code

If you bought a code — a gift card, a retail code, or a pre-order code — redeem it in the store before you download. On PS5, go to Settings, then Users and Accounts, then Account, then Payment and Subscriptions, and choose Redeem Codes. Enter the code exactly as printed, and the game will appear in your library ready to download. On Xbox, open the Microsoft Store and use the Redeem option from the store menu, then enter the code the same way. Redeem it on the account you actually play on — a code used on a different profile will not be available on your main one, and that is one of the most common reasons a game seems to disappear after redeeming.
