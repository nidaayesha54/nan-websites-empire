How to use the shape combiner

  1. Enable 2–3 shapes. Minimalist logos almost never need more. Two overlapping shapes is the sweet spot.
  2. Choose shapes and colors. Circles feel friendly, triangles feel dynamic, squares feel stable, lines feel fast. Stick to 1–2 colors — see our minimalist color guide.
  3. Position and rotate. Overlap shapes to create new forms; negative space between them counts as design too.
  4. Download the SVG. You get a true vector file — infinitely scalable, free for commercial use.

Design tips for minimal marks

  • One idea per logo. If you can't describe the mark in five words, remove something.
  • Test at 32 pixels. Shrink your browser zoom — if the mark survives, it's minimal enough.
  • Try one color. Set both shapes to black. If the composition still works, the geometry is strong.
