# NAN Calculators — Publish Guide

## Plugin tayyar hai ✅
`nan-calculators/` folder me poora plugin hai: 4 shortcodes (EOBI, overtime, gratuity, age), English + Urdu, koi tracking nahi, koi external calls nahi.

## Step 1 — Zip banao
Apne computer par `nan-calculators` folder ko zip karo (folder ka naam `nan-calculators` hi rehna chahiye, version number mat lagao).

## Step 2 — Apni site par test karo (WordPress login chahiye)
1. WordPress admin kholo → **Plugins → Add New → Upload Plugin**
2. Zip upload karo → **Install Now** → **Activate**
3. Koi page/post kholo aur likho: `[nan_eobi lang="ur"]`
4. Page dekho — calculator nazar aana chahiye. Teeno aur shortcodes bhi try karo:
   - `[nan_overtime]` `[nan_gratuity]` `[nan_age]`
   - English ke liye `lang="en"` ya lang likho hi mat

## Step 3 — WordPress.org par submit (baad me, jab test OK ho)
1. wordpress.org/plugins me **tumhara account** banao (free)
2. "Add your plugin" par zip upload karo — review me kuch din lagte hain
3. Approve hone ke baad duniya bhar ke log install kar sakenge = **free marketing + backlinks**

## Step 4 — Pro version (future earning)
Jab free version ke users a jayen to paid "Pro" banao:
- Extra calculators (income tax, zakat, loan/EMI)
- PDF export / result print
- Ad-free + priority support
- Price idea: $19–$49 one-time ya $5/month

## Yaad rakho
- Plugin me **koi "Nida" naam nahi** — sirf NAN branding hai ✅
- Koi user data collect nahi hota — privacy policy ke liye safe ✅
- Formulas tumhari verified websites wale hi hain ✅
