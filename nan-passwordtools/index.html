    FAQs

    Are the generated passwords truly secure?

    Yes. Passwords are drawn character-by-character using crypto.getRandomValues(), the browser's cryptographically secure random number generator. This is the same entropy source operating systems and banks use — not the predictable Math.random() many sites rely on.

    Do my passwords leave my device?

    No. All three tools run 100% in your browser. Nothing is uploaded, nothing is logged, nothing is stored. You can even disconnect from the internet after the page loads and the tools keep working.

    How long should my password be?

    Aim for 16+ characters for important accounts (email, banking, social media) with all character types enabled. A 16-character password from the full set has about 105 bits of entropy — far beyond what brute force can crack. For Wi-Fi or legacy systems limited to shorter lengths, use the maximum allowed with all types on.

    Is a passphrase better than a random password?

    For passwords you must memorize (like your password manager's master password), yes — a 5-word passphrase is easy to remember and still very strong (~65 bits). For accounts stored in a password manager, a long random password is ideal.

    Should I change passwords regularly?

    Modern guidance (NIST SP 800-63) says: no, not on a schedule — forced rotation makes people pick weaker passwords. Instead: use a unique strong password per account, enable two-factor authentication (2FA), and change a password immediately if that service reports a breach.
