How this stock return calculator works

Total return measures everything you gained: price appreciation plus dividends, relative to what you invested.

Total return % = (Sale proceeds − Buy cost + Dividends) ÷ Buy cost × 100

Annualized return (CAGR) converts that into an equivalent yearly rate, so a 3-year trade can be fairly compared with a 10-year one:

CAGR = (Ending value ÷ Beginning value)1 ÷ years − 1

FAQ

How is annualized return calculated? +
Annualized return (CAGR) = (ending value ÷ beginning value)^(1 ÷ years) − 1. It smooths your total gain into an equivalent yearly rate.
Should dividends be included in stock return? +
Yes — total return includes both price appreciation and dividends received. Ignoring dividends understates your true gain, especially on dividend stocks held for years.
