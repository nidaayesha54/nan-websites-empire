Buy It From the Real Store Only

The first rule is the one that protects you from everything else: buy GTA 6 only from the PlayStation Store or the Xbox Store. The game costs $79.99 for the Standard Edition and $99.99 for the Ultimate Edition, and those stores are the only places selling it. There is no PC version at launch, and no legitimate PC download exists anywhere — any site offering one is a scam. GTA 6 is also not on Game Pass or PS Plus, on any tier, so a "free with subscription" offer is fake too.

Free Up 212 GB First

Before you buy anything, make room. GTA 6 is a 212 GB download, and it needs 212 GB free — not 212 GB total. Check your storage before you buy, and delete or move games you are not playing if you are short. A download that has nowhere to go will sit at 0 percent forever, and the fix is freeing space, not restarting anything.

On PS5, also check the system software before you start: GTA 6 needs PS5 system software 26.07-14.23.00 to run properly at launch. Go to Settings, then System, then System Software, and install anything pending before you start the download. Ten minutes of checking now is worth hours of waiting later, on the busiest night of the year.

Preload, Then Wait for Midnight

Preloading is the smart move: it downloads the full 212 GB before launch, so you do not have to wait on launch night. What preloading does not do is unlock the game. GTA 6 stays locked until midnight local time in your store region, and until that moment the game shows a padlock. That padlock is the single most reported "problem" of the launch, and it is not a problem at all — check the countdown timer on the store page, because that timer, not the download bar, tells you when you can play.

Do not delete the game to fix the padlock. Deleting a 212 GB install means downloading it all over again, on the busiest night of the year, for no reason. The game is not broken, it is not stuck, and it is not missing — it is waiting for midnight, and so are you.

Downloading on PS5

On PS5, open the PlayStation Store, search for GTA 6, and buy it from the game's page. The download starts automatically after purchase. If you preloaded the game before launch, the full 212 GB is already on your console and there is nothing more to download — just the midnight unlock to wait for. If you bought a code — a gift card, a retail code, or a pre-order code — redeem it first: go to Settings, then Users and Accounts, then Account, then Payment and Subscriptions, and choose Redeem Codes. Enter the code exactly as printed, and the game will appear in your library ready to download.

Redeem the code on the account you actually play on — a code redeemed on another profile will not be available on your main one.

Downloading on Xbox

On Xbox, open the Microsoft Store, search for GTA 6, and buy it there. After purchase, the game appears in your library: open the Store, go to Full Library, then Owned Games, and choose Install. Turn on automatic updates, and leave the console in Sleep mode rather than shutting it down fully — Sleep mode lets downloads and updates finish in the background, while a full shutdown downloads nothing. To redeem a code on Xbox, open the Microsoft Store and use the Redeem option from the store menu, then enter the code the same way.

The same midnight rule applies: the game unlocks at midnight in your store region. If the game shows as owned but not installed, install it from Owned Games rather than searching the store again.

If the Download Gets Stuck

If the download will not start, or stalls at 0 percent, work through the verified fixes in order. On PS5, first check that system software 26.07-14.23.00 is installed, then check the countdown timer — a game that has not unlocked yet can look like a stalled download. Then go to Downloads and Uploads, Pause the download, and Resume it: that restart clears most stalls. If the game looks locked, use Restore Licenses — highlight GTA 6 on the home screen, press Options, and choose Restore License.

On Xbox, check for pending updates in My Games and Apps, then Manage, then Updates — and install everything pending for the game and the console. If the queue is still stuck, do the full power cycle: hold the power button for ten seconds, wait, and power back on.
